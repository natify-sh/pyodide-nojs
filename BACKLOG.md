## 2. Work: files and descriptors (what is still different is in `docs/DIFFERENCES.md`)

* **W1 crashes and hangs:** done (the whence trap, `read(0, 0)`, closing the preopens, the lseek overflow, a pending exception after `close(1)`; after `close(1)` the next `open()` is 1 as in Pyodide, `print` still fails with EBADF and a run that ends after `close(1)` is quiet).
* **W2 `/dev` and `/proc` as virtual objects in the adapter:** DONE (`wasm/adapter/dev.h`, `tests/test_dev.py`): the whole `/dev` and `/proc` subtrees are the adapter's, the same on every OS and with no host help (what Pyodide has: `/dev/{null,tty,tty1,random,urandom,shm,stdin,stdout,stderr}`, `/proc/self/fd`; no `zero`/`full`/`fd`). Left: `/dev/shm` is an empty read-only directory (Pyodide's holds `tmp` and is writable); nothing can be created under `/dev` (EACCES; Pyodide lets a program mutate its MEMFS `/dev`); a mount at or below `/dev` or `/proc` is refused with a ValueError; `open('/proc/self/fd/N')` is EACCES as in Pyodide (Linux reopens); `/dev/stdin|stdout|stderr` are character devices and `/dev/random`/`urandom` mode 0555 as in Pyodide (Linux: links, 0666). Also left, recorded: a symlink in the guest root that points into `/dev` or `/proc` is ENOENT, and so is a path that goes down into them and comes back with `..` (`/dev/../tmp`): the tree is classified lexically by the first names; a relative path that leaves the virtual tree from a `/dev` or `/proc` directory descriptor (`'../tmp'` with `dir_fd`) is EBADF; a path with `..` after a name is walked twice (`stat('/tmp/a/b/../b/c/f')` 387 us against 70 us without `..`); `/proc/self/fd/N` for a file with no recorded path: `lstat` works, `readlink` is ENOENT.
* **W3 errors and paths:** DONE, measured against Pyodide 315.0.0-alpha.2 and Linux and held by `tests/test_paths_errno.py` (both packagings): an empty path is ENOENT in every call that takes a path, `rmdir('d/')`/`rmtree('d/')` work, `read` of a directory descriptor is EISDIR, `posix_fadvise` advice outside 0..5 is EINVAL, `truncate` of a file with no write bit is EACCES (Pyodide's model), chdir/fchdir into the virtual directories as Pyodide. Left: unknown flags of `fstatat`/`faccessat` (`flags=8`, `0x4`) are accepted (Linux EINVAL; musl does not pass them on from the libc functions, so only a raw syscall sees it); `access(f, X_OK)` on a plain file is EACCES here and ok in Pyodide's MEMFS (root on Linux says EACCES); a relative path that leaves a `/dev` or `/proc` directory DESCRIPTOR is still EBADF (the cwd case is done).
* **W5 descriptor numbering:** DONE. A guest number is an index into the adapter's table of objects (`vfd.h`: `Vt`, 4096 numbers) with no relation to a WASI descriptor: the first `open()` is 3, every `open`/`dup`/`pipe`/`socket`/`F_DUPFD` gives the lowest free number, `dup2` takes any number below 4096, `EMFILE` only when the table is full; the object holds its WASI descriptor, path, open flags and directory snapshot; no preopen number is reachable; mmap keeps a reference to the object (`tests/test_descriptors.py`). Left: `F_DUPFD` with a minimum of 4096 or more is EINVAL (Pyodide accepts any), the last number is 4095 (Pyodide's `open` reaches 4096), and `os.set_inheritable(fd, True)` stays a no-op (the libc answers FIOCLEX itself).
* **W6** `st_nlink`, `st_blocks` differences (host-dependent). Still different in a listing (`files_dirs.py`): a name removed or renamed while a `scandir` loop runs is still listed (Pyodide skips what is gone); a 5000-name `listdir` takes 0.13 s where Pyodide takes 0.005 s (wasmtime's `fd_readdir` stats every entry).
* Known partial (platform limits, in the audit): `mknodat` FIFO/char/block/socket (WASI cannot create), `utimensat` outside 1970..2554 (WASI u64 ns), `symlinkat` across preopens (cap-std), epoll (3 `__syscall_epoll_*`: ENOSYS, no decision), `_emscripten_system` (ENOSYS on purpose: a shell would be a sandbox escape).
* A descriptor that is open but no directory (a pipe, a socket, a file, a standard stream) used as `dir_fd` with a relative path is ENOTDIR in every *at call (Linux; Pyodide says ENOENT for a pipe or socket and ENOTDIR for the rest, and EBADF is kept for a closed number); `utime` on a pipe, a socket or a standard stream is 0 (as Pyodide's `utime(1)`). A program that ends with all 4093 numbers in use fails in the wrapper (`pyodide_nojs_run` opens its status file after the program: EMFILE, status 255 / -1; Pyodide's `runPython` needs no descriptor). A dlopen'd side module that imports a WASI fd function outside `_wasm.WASI_ROUTED` would get raw guest numbers (none does today).
